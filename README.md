# Florescer — apresentação e login

Tela de entrada redesenhada em duas colunas, com apresentação do site e formulário de login/cadastro. A lógica do calendário, perfis e área Entre Nós foi mantida.

## Rodar
Abra esta pasta no VS Code e execute:

```bash
npm install
npm run dev
```

Use o endereço informado pelo Vite. Node.js LTS recomendado.

## Atenção
As contas e os dados deste protótipo são locais ao navegador; o login não é autenticação de produção. O atalho de ajuda não oferece sigilo garantido.


## Central de Ajuda compacta
As ações 190/180 ficam visíveis imediatamente. As explicações de sinais, tipos, direitos e contatos ficam em painéis HTML `<details>` recolhíveis. A lógica do calendário, login e registros foi preservada.
